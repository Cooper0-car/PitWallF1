Pitwall F1 — 안드로이드 앱(PWA)

[올릴 파일 6개] 폴더 없이 전부 저장소 맨 위(루트)에
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, icon-maskable-512.png

[폰에서 올리기]
 1. 깃허브 저장소 → Add file → Upload files
 2. 위 6개 파일 전부 선택 → Commit changes
    (index.html 은 이미 있으면 덮어써짐)
 3. 1~2분 기다림 (Pages가 다시 배포됨)

[설치]
 1. 폰 "크롬"에서 https://내아이디.github.io/저장소이름/ 열기
 2. 한 번 새로고침
 3. ⋮ → "앱 설치" 또는 "홈 화면에 추가" → 설치
